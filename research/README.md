# Public client provenance

[`manifest.json`](manifest.json) records the 39 BridgeZone JavaScript bundles
captured from public pages loaded in Edge on 2026-10-08. It lists each original
URL, byte size, and SHA-256 hash. The local copies matched those entries on
2026-10-09.

The raw bundles are third-party code and are not mirrored in XOX. The manifest
documents the evidence used to inspect the client contract; it does not imply
that these files still match the live game. The game's server source and private
anti-cheat rules were not present in the public browser capture.
